## Помилка
**Симптом:** `403 Permission denied` під час `git push`.

**Причина:** Авторизація у GitHub виконана під іншим акаунтом без прав запису до репозиторію.

**Рішення:**
1. Перевірити `git remote -v`.
2. Очистити застарілі credentials для `github.com`.
3. Повторно авторизуватися під правильним акаунтом (`golden-apple1`) і виконати push.
